# enhance-prompt

This skill transforms vague UI ideas into polished, Stitch-optimized prompts. It enhances specificity, adds UI/UX keywords, injects design system context, and structures output for better generation results.

## Core Capabilities
- **Prompt Expansion**: Adds detail to simple user requests.
- **Design Context**: Injects project-specific design tokens and style rules.
- **Structuring**: Formats prompts to guide the Stitch generative model more effectively.
