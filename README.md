# Blackjack Premium Mobile

A high-stakes, luxury Blackjack mobile application built with React, TypeScript, and Tailwind CSS.

## Features
- **Premium VIP Aesthetic**: Forest green felt, mahogany borders, and gold-leaf accents.
- **Glassmorphism UI**: Modern, frosted-glass HUD and controls.
- **Full Game Logic**: Realistic deck shuffling, card dealing, and scoring.
- **Mobile Optimized**: Ergonomic touch controls and vertical layout.

## Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

## Installation

1. Clone the repository:
   ```bash
   git clone <REMOTE_URL>
   cd blackjack-premium
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

## Technologies Used
- **React** for UI components.
- **TypeScript** for type-safe game logic.
- **Tailwind CSS** for premium styling and glassmorphism.
- **Vite** for fast development.

## Game Rules
- Dealer stands on 17.
- Blackjack pays 3:2.
- VIP Balance: Start with $250,000.
